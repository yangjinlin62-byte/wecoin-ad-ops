# 01 快速开始

## 环境要求

| 项 | 要求 |
|---|---|
| Node.js | ≥ 22.19 |
| Chrome | 任意近期版本 |
| 操作系统 | Windows / macOS / Linux |
| 网络 | 能访问 `channels.weixin.qq.com` |

## 第一步：启动能调试的 Chrome

这个技能通过 **CDP（Chrome DevTools Protocol）** 操作真实浏览器，不是调私有接口。

```powershell
# Windows
& "C:\Program Files\Google\Chrome\Application\chrome.exe" `
  --remote-debugging-port=9444 `
  --user-data-dir="D:\wecoin-profile" `
  --no-first-run `
  "https://channels.weixin.qq.com/promote/pages/platform/order-list"
```

```bash
# macOS
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --remote-debugging-port=9444 \
  --user-data-dir="$HOME/wecoin-profile" \
  --no-first-run \
  "https://channels.weixin.qq.com/promote/pages/platform/order-list"
```

**要点**：
- `--user-data-dir` 指定一个**独立目录**（不要用默认 profile）；
- 登录后**不要关闭这个窗口**，关了登录可能丢；
- 两个投放账户就开两个端口（9444 / 9445），用不同 `user-data-dir`。

## 第二步：登录

在弹出的 Chrome 里扫码登录**你的微视号/视频号账号**。

登录成功后，页面应该停在「订单列表」。

## 第三步：运行 setup

```bash
node scripts/setup.js --port=9444
```

它会自动：
1. 检查 CDP 通不通；
2. 调 `getUserPrepare` 拿到你的**投放账户名**；
3. 扫描商品目录，列出可用商品；
4. 读取排除名单；
5. 生成 `config/rules.json`。

## 第四步：确认配置

打开生成好的 `config/rules.json`，确认：

```json
{
  "accounts": [
    {
      "id": "account1",
      "label": "你的投放账户名",
      "cdpPort": 9444,
      "cashFloor": 3000
    }
  ]
}
```

- `label` 应该是你的真实账户名（比如「元智成文化」）；
- `cashFloor` 是保留余额，按你的资金情况改。

## 第五步：验证

```bash
node scripts/catalog.js sync --account=account1
```

能列出视频目录 = 安装成功。

## 常见问题

**Q: setup 报 `CDP 连不上`？**
- Chrome 没启动，或端口不对；
- 检查 `chrome --remote-debugging-port=9444` 是否真的跑起来了。

**Q: setup 报 `未登录`？**
- 页面停在登录页，需要在那个 Chrome 里扫码。

**Q: 两个账户怎么配？**
- 开两个 Chrome（9444 / 9445），分别登录，`rules.json` 里写两条 account。

**Q: 关了 Chrome 登录丢了？**
- `--user-data-dir` 的登录态有时效；重新扫码即可。
