# 05 配置说明

`config/rules.json` 是这套系统唯一的配置入口。`setup.js` 会自动生成，通常不用手改。

## 完整结构

```json
{
  "version": 1,
  "accounts": [
    {
      "id": "account1",
      "label": "元智成文化",
      "operator": "锦淋",
      "cdpPort": 9444,
      "cashFloor": 3000
    }
  ],
  "targeting": {
    "ageRange": [],
    "note": "[] 不限年龄"
  },
  "videoWindow": {
    "minCreateTime": "2026-07-01T00:00:00+08:00"
  },
  "batch": {
    "maxVideos": 60,
    "maxPlans": 50,
    "allowedBudgets": [300, 600, 800, 1000, 1200, 1300, 1400, 1500, 2000]
  },
  "bidCaps": {
    "成交数": { "min": 90, "max": 110, "hardMax": 130 },
    "成交ROI": { "min": 0.6, "max": 0.8, "recommended": 0.7 },
    "净ROI": { "min": 0.6, "max": 0.8, "recommended": 0.7 },
    "净成交数": { "min": 600, "max": 700, "budgetMultiplier": 2 }
  },
  "productTiers": {
    "10000501804864": "59.9",
    "10001808219265": "399"
  },
  "billing": {
    "default": "mix"
  }
}
```

## 字段说明

### `accounts[]` — 账户列表

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 内部标识，建议 `account1` / `account2` |
| `label` | ✅ | **投放账户真实名**（如「元智成文化」），setup 自动填 |
| `operator` | ❌ | 操作人（登录的管理员），仅展示用 |
| `cdpPort` | ✅ | Chrome 调试端口，每个账户一个 |
| `cashFloor` | ✅ | 现金保留底线（元），建单时不会动用这部分 |

### `targeting.ageRange` — 年龄

| 值 | 含义 |
|---|---|
| `[]` | **不限年龄** |
| `[2,3,4]` | 25-29 / 30-39 / 40-49 岁 |
| `[1,2,3,4,5]` | 18-49 岁（更宽）|

### `videoWindow.minCreateTime` — 视频时间窗

只投这个时间之后创建的视频。默认 `2026-07-01`。

### `batch` — 批量限制

| 字段 | 说明 |
|---|---|
| `maxVideos` | 单计划最多视频数（默认 60）|
| `maxPlans` | 单次建单最多计划数（默认 50）|
| `allowedBudgets` | 允许的预算值（建单时会校验）|

### `bidCaps` — 出价上下限

建单时会强制校验，超出会报 `BID_TOO_HIGH` / `BID_TOO_LOW`。

### `productTiers` — 商品层

商品 ID → `59.9` 或 `399`。用于判断预算规则（399 需要 2 倍）。

### `billing.default` — 扣费模式

| 值 | 含义 |
|---|---|
| `mix` | 实时:预付 1:1 |
| `realtime` | 全实时（微信豆多、现金少）|
| `prepay` | 全预付（现金充足）|

## 常见修改

### 改现金底线
```json
"cashFloor": 5000
```

### 改年龄
```json
"targeting": { "ageRange": [2, 3, 4] }
```

### 加一个新账户
```json
"accounts": [
  { "id": "account1", "label": "元智成文化", "cdpPort": 9444, "cashFloor": 3000 },
  { "id": "account2", "label": "元智成B户", "cdpPort": 9445, "cashFloor": 5000 }
]
```

### 换主投商品
把 `productTiers` 里的商品 ID 换成你的即可（setup 会扫描出来）。

## 注意

- **`label` 用平台拉到的真实名**，不要自己编（否则看板/报表会混）；
- **每个账户的排除名单 ID 不同**，不能互相抄；
- 改完配置后跑一次 `node scripts/catalog.js sync` 验证。
